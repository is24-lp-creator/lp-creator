GPT Builder / Overview

Component Library

Diese Startseite dient als neutraler Einstieg in die GitHub-Version der Library. Waehle links einen Builder und oeffne danach die passende Kategorie, um die einzelnen Module zu sehen.

Startseite

Waehle links eine Kategorie

Landing Page Builder und E-Mail Builder starten bewusst eingeklappt. So wirkt die Library beim ersten Aufruf ruhiger und eher wie ein eigenstaendiges Tool.
